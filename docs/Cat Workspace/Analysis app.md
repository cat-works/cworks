# analysis.app

## コンセプト

- GUI 上でファイルを解析する Web アプリ
- 解析した構造を表し編集もサポートしたい

## 仕様

- プログラムで拡張可能なバイナリ解析アプリ
- /usr/lib/treehex.lua で拡張 SDK を提供する
- `<obj>::parse(file: File)`で読み込み
- すべての型は `<obj>::render()` で描画される
- 文字列、数値、辞書型の骨組み等のプリミティブ型は別手段で実装
- ~~その型の UI デザインを頼みたい~~　→ Material UI のやつを使う

## UI に関する要望

- スマホでも動くようにしたいからスマホ向けの UI がほしい (できれば)
- ただこれはなくても十分使いやすければ ok
- ツリー構造が主になるからそれに適応する UI にしてほしい（エクスプローラーとかが例）
- 構造を編集する画面の UI デザインをお願いしたい
- バイナリビュアー（色付けもする予定）
- 構造の編集画面（テキストベース）
- 解析した構造を見るやつ（とりあえず空間があればいい）
- の 3 つが少なくともあれば大丈夫
